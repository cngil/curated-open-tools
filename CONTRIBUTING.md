# Contributing

Suggestions and corrections are welcome. Open an issue to discuss a project, or submit a pull request.

Before submitting, check that the repository:

1. Has at least 1,000 stars and is not archived or clearly deprecated.
2. Has a push within the last six calendar months. Check recent releases, issues, and human contributions as additional evidence of maintenance.
3. Fits an existing category, or explain why a new category is useful.
4. Has an accurate, concise description and a license label linked to an authoritative license source. If the license cannot be identified, say so and link to the repository.

In your pull request, include the repository URL, star count, last push date, evidence of maintenance, and license source. Avoid promotional language and duplicate entries. License and availability may differ for hosted services, models, and individual components.
