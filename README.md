# Curated Open Tools

A curated directory of useful software for AI, development, creative work, and self-hosting.

## Inclusion criteria

- At least **1,000 GitHub stars** at the time of review.
- At least one repository push in the previous **six calendar months**. Recent pushes are a screening signal, not proof of active maintenance; reviewers should also check releases, issues, and human activity.
- The repository must not be archived or clearly deprecated, and must fit a category below.
- A license must be identified or marked **Not identified** for follow-up. Repository licenses may not cover models, assets, services, or every component.

Reviewed: **2026-11-01**. Stars, activity, and licensing can change. License labels below are GitHub's detected SPDX identifier, not legal advice; follow the link and check the repository for dual licenses and exceptions. **Not identified** means GitHub did not provide a usable SPDX identifier, not that the project has no license.

See [CONTRIBUTING.md](CONTRIBUTING.md) to suggest a repository or correction.
